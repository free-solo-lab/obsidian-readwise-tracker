# Readwise Reading Tracker 1.3.1

- AI dialogs, translation and the other features that use Codex Bridge now look for the plugin under its new id, `free-solo-codex-bridge` (**Free Solo Codex Bridge**, version 1.0.1 or newer). The old id `codex-bridge` belongs to an unrelated plugin in the Obsidian catalog.
- If you installed Codex Bridge 1.0.0 by hand, update it from its [releases page](https://github.com/free-solo-lab/obsidian-codex-bridge/releases) and enable it again.

## Installation

Download `main.js`, `manifest.json` and `styles.css` from this release and place them in:

```text
.obsidian/plugins/readwise-reading-tracker/
```

Restart Obsidian or reload the plugin after replacing the files.
